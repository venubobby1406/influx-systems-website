# INFLUX SYSTEMS — Website

Marketing site for **INFLUX SYSTEMS**, a computer sales & service, CCTV, networking and office-setup business in Shapur Nagar, Hyderabad.

Built with React 19, TypeScript, Vite 7 and Tailwind CSS 4. The production build is inlined into a single `index.html` via `vite-plugin-singlefile`.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:5173/.

## Production build

```bash
npm run build
npm run preview
```

The output is written to `dist/`.

## Deployment

Every push to `main` triggers the **Deploy to GitHub Pages** workflow (`.github/workflows/deploy.yml`), which builds the site and publishes `dist/` to GitHub Pages.

Live site: https://venubobby1406.github.io/influx-systems-website/
